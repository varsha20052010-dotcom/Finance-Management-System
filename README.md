Finance Management System using SQL

Project Overview

The Finance Management System is a SQL-based database project developed to manage and organize financial records efficiently. The project helps maintain account details, categorize transactions, record income and expenses, and manage monthly budgets. The main objective of this project is to store financial information in a structured format and retrieve the required data using SQL queries.

Objectives

- To maintain account information in a database.
- To organize financial transactions by category.
- To record transaction dates, types, amounts, and descriptions.
- To manage monthly budgets for different categories.
- To retrieve and analyze financial information using SQL queries.
- To understand relational database design and data management.

Technologies Used

- SQL
- MySQL
- Relational Database Management System (RDBMS)

Database Structure

The project consists of the following tables:

1. Categories
Stores different financial categories such as Food, Travel, Rent, Shopping, and Entertainment.

2. Accounts
Stores account details, including account name, account type, and opening balance.

3. Transactions
Stores transaction details such as account ID, category ID, transaction type, transaction date, amount, and description.

4. Budget
Stores monthly budget information for different expense categories, including budget month and budget amount.

SQL Concepts Used

- Table creation
- Primary keys and foreign keys
- AUTO_INCREMENT
- NOT NULL and DEFAULT constraints
- Data insertion
- SELECT statements
- WHERE conditions
- ORDER BY
- Aggregate functions

Project Features

- Organizes financial accounts and categories.
- Maintains transaction records in a structured database.
- Links transactions with accounts and categories using foreign keys.
- Stores monthly budget details.
- Supports data retrieval through SQL queries.
- Helps practice financial data organization and database management.
